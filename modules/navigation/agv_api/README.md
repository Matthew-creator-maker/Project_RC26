# 阻塞回退版导航说明

## 行为目标

本版本不实现程序级绕路，也不下发关闭底盘安全/避障功能的配置。

- 正常行驶时：继续使用底盘控制器自身的激光/安全避障能力。
- 出现短暂障碍时：允许 1.5 秒去抖，避免单帧 `blocked` 或 `SUSPENDED` 抖动误触发。
- 持续阻塞达到 1.5 秒：立即取消当前目标，不等待程序或底盘继续尝试绕路。
- 取消确认后：从机器人当前实际位置导航回本段的上一任务点。
- 回到上一任务点并连续确认静止后：抛出 `DynamicObstacleTimeout`，上层比赛流程可跳过当前不可达目标。

## 回退命令

正常段导航仍可发送 `source_id + id`。

阻塞回退时使用 `navigate_to("", previous_station)`；底层 API 在 `source` 为空时只发送：

```json
{"id": "LM1"}
```

这样不会向控制器发送空字符串 `source_id`，而是让底盘从当前真实位置规划回上一任务点。

## 相关参数

`config/task_config.json`：

- `blocked_timeout_s`: `1.5`
- `suspended_timeout_s`: `1.5`
- `navigation_timeout_s`: `180.0`

如果现场 `blocked` 信号有明显抖动，可以把前两个参数提高到 `2.0 ~ 3.0` 秒；不建议设成 `0`，否则单帧安全停车就可能触发回退。

## 安全说明

回退仍通过底盘导航 API 完成，不使用开环倒车速度指令，因此底盘原生避障/安全停车仍有机会生效。程序本身不读取雷达点云做局部绕障，也不会主动寻找备用路线。
