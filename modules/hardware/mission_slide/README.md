# 比赛导轨控制

本目录包含第一份压缩包的 `slide.py` 驱动与示例，以及比赛流程使用的 `controller.py`。
默认串口 `/dev/ttyACM0`、波特率 38400；安装 `pyserial` 后运行。

默认 LM3、LM4 下降到 `-7200000 inc`，离开点位前回到 `0 inc`。这两个数字来自提供的 `demo.py` 和 `reposition.py`；上机前必须核实设备零点、机械限位、运动方向以及机械臂与环境间隙。控制器重启可能将当前位置设为零，此时不能直接沿用绝对位置，需重新标定。按实测值修改 `controller.py` 中的 `LOW_POSITION_INC` 和 `TRAVEL_POSITION_INC`。

导轨移动等待实际位置与目标位置误差不超过 20000 inc，且驱动器报告到位；超时、通信故障或未使能会中止任务。首次识别播报与每轮抓取在到达 LM3、LM4 后下降，离开前升起；仅导航测试和预览不会操作导轨。
